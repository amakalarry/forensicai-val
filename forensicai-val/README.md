# ForensicAI-VAL — reference prototype and refusal test

https://github.com/amakalarry/forensicai-val

Built 29 September 2026 for the Digital Science 2026 Catalyst Grant application.
This is the evidence behind the "Where You Are Today" section of the proposal.

## What this is

A working reference implementation of the checker described in the proposal, plus
the three-arm test that produced the results quoted there. It is deliberately
narrow: five checks, one package shape. It is not the MLflow plugin — that is
what the grant would fund.

## Layout

```
tool/faval.py            the agent: inventory -> plan -> execute -> classify -> refuse -> export
demo/make_package.py     builds the seeded experiment package (3 faults)
demo/make_variants.py    builds the repaired control and the post-registration tamper case
demo/experiment_package/ seeded package
demo/package_clean/      repaired control
demo/package_tampered/   registered weights altered after the manifest was written
demo/review_output/      review report + audit log, seeded run
demo/out_clean/          review report + audit log, control
demo/out_tampered/       review report + audit log, tamper case
proposal.md              the 1,500-word application text
```

## Reproduce

```bash
python3 demo/make_package.py
python3 demo/make_variants.py
python3 tool/faval.py demo/experiment_package demo/review_output
python3 tool/faval.py demo/package_clean       demo/out_clean
python3 tool/faval.py demo/package_tampered    demo/out_tampered
```

Requires Python 3.9+ and numpy (used only to generate the synthetic package;
the checker itself is standard library only).

## Results as run

| Package | Decision | Verified | Discrepancy | Insufficient |
|---|---|---:|---:|---:|
| Seeded faults | REFUSE_TO_CERTIFY | 2 | 2 | 1 |
| Repaired control | CONSISTENT_WITH_REGISTERED_EVIDENCE | 5 | 0 | 0 |
| Post-registration tamper | REFUSE_TO_CERTIFY | 1 | 3 | 1 |

Seeded run detail: stale figure traced to `run_2026-06-14_a3f1` against a package
run of `run_2026-08-02_9c7d`; mAP@50 recomputed as 0.8569 against a reported
0.8870; dataset identity reported as insufficient evidence rather than inferred.

The control arm matters as much as the fault arms: the agent raised no false
alerts on the repaired package, and still declined to approve it — it returned
the package for a human decision rather than certifying it.

## Honest scope

- The experiment package is **synthetic**, structured to match an Ultralytics
  YOLOv11 run directory. It is not real data from any paper. Pointing this at
  the real crime-scene dataset runs is the next step, and needs the co-authors'
  agreement.
- **Figures are real plots**, generated by `demo/plotting.py` from each package's
  own predictions and `results.csv`. `fig3_class_performance.png` in the seeded
  package genuinely shows the earlier run's numbers (mAP@50 0.7982) while the
  package documents the later run (0.8569) — open it and the discrepancy the
  checker reports is visible on the chart.
- **`weights/*.pt` are random-byte placeholders**, not torch checkpoints. The
  checker only hashes them, so no model is ever loaded. They exist to exercise
  the artifact-integrity check and the post-registration tamper case.
- mAP@50 is genuinely recomputed (greedy IoU matching, all-point interpolated
  AP) — the discrepancy the agent reports is a real numerical disagreement, not
  a scripted message.
- No language model is used anywhere in the numeric path. The "agent" part
  here is the plan step; the intelligence claimed in the proposal is about
  choosing checks for incomplete packages, which this prototype only gestures at.
- No pilot users, no measured reviewer-time savings. Those are what the grant
  would establish.

## Pointing it at a real run

`tool/faval.py <package_dir> <output_dir>`. The checker expects some subset of:
`run_manifest.json`, `args.yaml`, `results.csv`, `figures/*.meta.json`,
`predictions/val_predictions.json`, `labels/val_ground_truth.json`,
`dataset/dataset.yaml`, `manuscript/reported_results.json`. Missing inputs
disable the corresponding check and are reported, not silently skipped.
